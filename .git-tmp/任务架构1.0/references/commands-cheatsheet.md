# 四个命令速查卡

## /分析架构 — 代码 → JSON

**输入**：已有项目目录
**输出**：architecture.json
**适用**：已有项目想纳入架构管理

关键步骤：
1. 扫描目录结构 → 识别模块边界
2. 分析 import 关系 → 确定依赖
3. 提取函数/类签名 → 定义接口
4. 生成 JSON → 汇报确认

---

## /创建架构 — 需求 → JSON

**输入**：需求描述（文字）
**输出**：architecture.json
**适用**：新项目从零开始

关键步骤：
1. 理解需求 → 设计模块划分
2. 确定依赖拓扑 → 分配优先级
3. 定义接口契约 → 编写测试用例
4. 生成 JSON → 展示依赖图确认

---

## /修改架构 — 需求变更 → 更新 JSON

**输入**：变更需求 + 现有 architecture.json
**输出**：更新后的 architecture.json
**适用**：需求变化，模块接口或文件需调整

关键步骤：
1. 定位受影响模块
2. 追踪依赖链（谁依赖了被修改的模块）
3. 更新接口定义 + 重置受影响模块状态
4. 追加变更记录

---

## /追加架构 — 新模块 → 更新 JSON

**输入**：新模块需求 + 现有 architecture.json
**输出**：追加了新模块的 architecture.json
**适用**：项目扩展，新增功能模块

关键步骤：
1. 确定新模块的依赖（精确到使用哪个接口）
2. 确定优先级（排在所有依赖之后）
3. 定义新模块的接口和文件
4. 追加到 JSON + 变更记录
