# 通用 CLI Agent 适配说明

通用 CLI Agent、Cursor、Windsurf、Cline、Continue 或自研编程智能体若没有专用适配文档，默认使用本说明。

最低执行要求：

1. 读取 `SKILL.md`。
2. 检查当前项目是否存在 `architecture.json`。
3. 若存在，任何代码、接口、数据、测试、文件或行为修改都先更新 `architecture/index.json` 或相关架构切片。
4. 用标准输出契约模拟模块智能体。
5. 可运行脚本时运行校验；不可运行时记录降级原因。
6. 最终更新验证证据、上下文恢复点和变更记录。

若智能体无法编辑文件，只能输出变更计划，不得声称已完成实现。

## 收尾门禁（C 档：一句话契约，极小注意力）

平台不支持 Stop hook（多数通用 CLI Agent）时，用一句话契约兜底。这是**唯一**需要进入模型注意力的门禁规则，刻意压到一行，避免重新堆叠流程负担：

> 声明任务完成前，必须运行 `python shared/scripts/gate_check.py <项目根>`；退出码非 0 时，只能汇报"已完成实现，未通过验证"，并把失败项写入上下文恢复点与变更记录。

- 这条契约把"做完没"的判断外包给脚本，模型不需要在注意力里持有具体检查项（架构合规/代码漂移/流程脱轨由脚本逐项判定）。
- `gate_check.py` 退出码：`0=PASS`、`1=FAIL`、`2=无法判定`（项目未启用架构管理，放行）。
- 能挂平台 hook 的环境优先用 A 档（见 `claude.md`）——hook 不进模型上下文，零注意力，比一句话契约更彻底。
