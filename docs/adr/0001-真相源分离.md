# ADR-0001：真相源分离（能力在仓库，状态在调用方）

- 状态：已采纳（自 1.1.2 起，rwgj 强化）
- 日期：2026-08-04（记录）

## 背景

技能包最初是"单文件 SKILL + 项目混装"：能力和项目状态放一起，多项目共用时互相污染，
技能仓库里混入业务架构，升级技能会覆盖项目状态。

## 决策

- **能力**（规则、脚本、模板、参考文档）永远在技能仓库（`skills/` + `shared/`）。
- **项目状态**（`architecture/`、`architecture.json`、`architecture/_state.json`）永远在调用方项目根目录。
- 本仓库 `.gitignore` 锚定根目录忽略 `architecture/`，确保仓库永不携带调用方状态。
- 共享文件按"项目根 `shared/` 优先 → 技能安装目录回退"两级解析。

## 后果

- ✅ 一个全局技能可安全服务任意多个项目；升级技能不触碰项目状态。
- ✅ `git clone` 下来的永远是纯能力，无业务数据泄露风险。
- ⚠️ 需要一套清晰的路径解析规则（见 LAYER.md「工具执行前置」），否则 Agent 会找错文件。
- ⚠️ 项目级复制模式（复制到项目根）会失去"一次更新多项目生效"的优势，属预期取舍。
