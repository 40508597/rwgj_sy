# ADR-0003：薄入口 + 按需加载（注意力保护）

- 状态：已采纳（Xl-Ai-Language 现行版）
- 日期：2026-08-04（记录）

## 背景

1.1.x 时代入口文件越写越厚，能力全塞进 SKILL.md；Agent 每次加载都全量吞入，
规则互相挤占注意力，参考文档（现 21 篇）一旦全量加载必然稀释关键约束。

## 决策

- `SKILL.md`（38 行）只做定位与路由，不承载规则。
- 四层能力按固定顺序路由：`xl-ai-language/LAYER.md`（路由）→ `project-depth-core/CORE.md`（想得深）→ `architecture-json/SCHEMA.md`（落得稳）→ `agent-protocol/PROTOCOL.md`（跑得广，仅按需）。
- 每层底部只列"详细参考路由"：按触发信号读取，默认不全量加载。
- 强制输出主会话回执（入口链路/触发原因/任务判定），禁止静默调用。

## 后果

- ✅ 加载成本恒定（薄入口），细节按需取用，注意力集中在当前任务。
- ✅ 路由顺序固定，多项目/多平台行为一致。
- ⚠️ 路由依赖 Agent 正确解析相对路径——故配套 LAYER.md「工具执行前置：先解析路径」强制动作。
- ⚠️ 层间规则有引用关系，改一层必须检查引用方（文档数字对账 + 引用完整性检查兜底）。
