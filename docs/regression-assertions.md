# 回归断言

这些场景用于判断任务架构能力是否被稀释。断言失败表示不能交付。

## 导出功能

必须出现并归位：

- 字段映射或导出范围。
- 权限校验。
- 大数据量处理。
- 失败恢复。
- 审计或导出记录。
- 测试责任。

## 管理类能力

不得把管理能力塞进普通用户页面。必须判断：

- 是否需要独立入口。
- 是否需要独立权限边界。
- 是否需要独立模块或子模块。
- 是否涉及数据维护、审计或运营反馈。

## 菜单栏

不得只生成横条。必须覆盖：

- 菜单项行为。
- 点击后的动作、反馈和失败处理。
- 激活/禁用/加载/错误状态。
- 下拉或层级关系。
- 路由、命令或动作绑定。
- 快捷键、键盘或可访问性需求（适用时）。

## 修 Bug

必须补：

- Bug 场景。
- 异常路径。
- 复现或验证方式。
- 测试责任。
- 变更记录。

## 新增模块

必须落位：

- 功能树。
- 模块树。
- 模块详情。
- 接口契约。
- 实现清单。
- 测试责任矩阵。
