# 能力地图

## 注意力保护区

```text
project-depth-core
  目标：想得深
  输入：用户自然语言需求
  输出：功能本体、功能簇、架构归位建议、影响联想

architecture-json
  目标：落得稳
  输入：深度理解结果
  输出：architecture/ 架构文件夹变更、实现清单、验证责任

agent-protocol
  目标：跑得广
  输入：已落位架构和执行结果
  输出：门禁结果、标准报告、跨平台适配说明
```

## 调用顺序

```text
总入口
→ project-depth-core
→ architecture-json
→ agent-protocol（按需）
```

## 禁止事项

- 不得从总入口直接写代码。
- 不得让 MCP/CLI 做功能簇展开。
- 不得让适配层决定项目架构。
- 不得把 `shared/` 复制后手改成多个分叉版本。

## CLI/MCP 边界

CLI 和可选 MCP 只能做确定性查验：

- 读取架构切片。
- 检查文件是否登记。
- 检查漂移。
- 校验输出结构。
- 检查回归断言关键词。

不能做：

- 功能簇展开。
- 架构归位决策。
- 模块边界设计。
- 项目深度判断。
