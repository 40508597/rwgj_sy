# 小命令降级

用户需求是「小命令」时自动降级，减少流程摩擦。本文件是小命令降级的规则真相源（词表见
`shared/assets/small-command-rules.json`，检测工具 `shared/scripts/detect_small_command.py`），
总入口 `skills/task-architecture/LAYER.md` 只保留路由与铁律。

## 判定工具

```bash
python shared/scripts/detect_small_command.py --request "<用户需求文本>" --project-root <项目根>
```

输出 JSON 含 `判定档位 / 有效档位 / 闭环类型 / 降级 / 受管项目 / 风险等级 / 命中依据 /
必须动作 / 禁止事项 / 功能簇要求 / 降级说明 / 回执`；`回执` 字段可直接贴到主会话。

## 判定链（顺序固定）

1. **拆分复合请求**：按分句和连接词识别各子任务，整体采用最严格档位。明确的“不要修改”“删除逻辑保持原样”等作为用户限制保留到命中依据与禁止事项；后续实际操作独立判定，不能被否定句遮蔽。否定范围有例外、连续操作或其他歧义时保留完整流程。
2. **只读与问答**：纯解释、查看可以完全跳过；含明确操作时不能被“看看”“这个技能怎么用”遮蔽。“查看架构”“架构是什么”保持轻量。
3. **操作判定**：完整流程优先于最小闭环；“修改架构”完整流程，“把按钮改成蓝色”最小闭环。未知操作不能被跳过词覆盖。
4. **高风险词升档**：实际意图中的删除/支付/生产/权限等高风险词命中且非完全跳过档 → 强制完整流程；中风险词保留档位但必须动作追加「风险确认」。仅在明确的标题、按钮文字、文案等编辑上下文中，把引用值视为文本；`把按钮文字改为“删除账户”` 是修改类最小闭环，`删除“生产数据库”`、`运行“删除生产数据”的脚本` 仍为完整流程。纯限制句与文案引用不算实际风险操作。
5. **受管降级**：非受管项目（无 `architecture.json` / `architecture/`）的最小闭环 → 完全跳过
6. 全部未命中 → 默认完整流程（拿不准一律完整流程）

明确的“不删除”“不修改”作为限制处理；“不要只查看”等否定范围有歧义的请求仍保守判定。
“只读打开/阅读”只有不含实际操作时才保持轻量。文案支持书名号和明确文字编辑上下文中的无引号值；
无引号值中出现后续操作标记或多个操作词时不屏蔽，仍逐句检查实际操作。

## 三档

| 档位 | 判定 | 动作 |
|------|------|------|
| **完全跳过** | 概念问答、一次性脚本、临时实验、纯只读查看（不因已有架构锚点升级） | 输出降级回执 → 用普通编程智能体能力直接处理，不进入三层流程 |
| **最小闭环** | 小命令但触及项目：启动/运行项目、运行单条命令、修改某个元素、小修改小修复 | 读状态 → **功能簇最小定位** → 定向修改 → 三重校验 |
| **完整流程** | 新项目从零、需求变更、功能扩展、重构、多模块设计、漂移排查、接口契约 | 三层路由照常 |

## 最小闭环两型

| 型 | 触发 | 必须动作 |
|----|------|----------|
| **运行类** | 启动/重启/运行项目、跑一下、单条命令（无代码或架构变更） | 读状态 → 功能簇最小定位 → 执行 → 记录验证证据（不做三重校验，避免空转与污染状态文件） |
| **修改类** | 修改/改一下/换个/修复 bug/加个/删个/优化一下（有变更） | 读状态 → 功能簇最小定位 → 定向修改 → 三重校验 |

## 三条铁律

1. **最小闭环不是零架构**：不得完全跳过功能簇，必须做功能簇最小定位——本次小命令落到哪个功能树节点、读哪个切片，定位后定向修改；不全量展开功能簇。
2. **非受管项目无锚点**：项目根没有 `architecture.json` 或 `architecture/` 时，最小闭环一律降为完全跳过。
3. **高风险词禁止降级**：高风险实际操作强制完整流程，纯问答和只读保留轻量档位；是否需要确认取决于实际操作与既有授权，不能只凭风险词反复询问。

## 降级回执（必须输出到主会话，禁止静默）

最小闭环（修改类）：

```text
✅ 已启用任务架构技能（小命令降级）
入口链路：SKILL.md → skills/task-architecture/LAYER.md
触发原因：detect_small_command.py 自动判定为小命令
降级档位：最小闭环（修改类）
要求：读状态 → 功能簇最小定位（不全量展开功能簇）→ 定向修改 → 三重校验
功能簇定位：[本次小命令触及的功能树节点，如 F2.1 虚拟运行时]
```

最小闭环（运行类）：

```text
✅ 已启用任务架构技能（小命令降级）
入口链路：SKILL.md → skills/task-architecture/LAYER.md
触发原因：detect_small_command.py 自动判定为小命令
降级档位：最小闭环（运行类）
要求：读状态 → 功能簇最小定位（不全量展开功能簇）→ 执行 → 记录验证证据（无变更不做三重校验）
功能簇定位：[本次小命令触及的功能树节点，如 F2.1 虚拟运行时]
```

完全跳过：

```text
✅ 已检查任务架构技能（小命令降级）
降级档位：完全跳过
原因：[概念问答 / 纯只读查看 / 一次性脚本或临时实验 / 项目非受管无锚点]
后续：使用普通编程智能体能力处理
```

完整流程档使用普通启动回执。同一任务只需一份可见回执，可合并摘要；档位未变不重复输出模板。

## 裁决边界

检测结果只做轻量建议；必须服从用户明确要求、安全风险裁决、当前项目有效根入口与登记模块/切片的事实和模型工程判断。
