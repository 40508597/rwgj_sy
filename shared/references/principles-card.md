# Xl-Ai-Language速记卡

供日常查找规范；详细规则以链接的职责层为准，不另立一套流程。

## 先定位，再行动

- [入口与范围](../../skills/xl-ai-language/LAYER.md)：任意编程智能体、项目语言和工程格式均可使用；只读、问答和一次性实验走轻量路径。
- [项目入口](../../SKILL.md#定位规则)：递归根按模块路由逐层进入，既有集中布局跟随指针；项目状态和证据留在项目中。
- [架构先行](../../skills/xl-ai-language/LAYER.md#设计与物化路由)：先更新实际变化的权威事实再编码；已覆盖实现补变更/测试/影响记录，不重写未变化设计。

## 设计深度

- [CORE](../../skills/project-depth-core/CORE.md) 的六大机制：最大主动性、功能簇展开、交互完整性、多层递进、分治与实现期循环展开。
- [功能全景](function-clusters.md)：核心、天然绑定、适用商业标配充分纳入设计，强相关衍生与关联功能完整列出，由用户取舍；候选不是实现授权。
- 功能树叶子可验收、可落位、可测试；仍需猜业务含义则继续展开。目录深度、文件数和实施批次不限制功能发现。
- [交互完整性](interaction-completeness.md)：覆盖适用的请求、处理、成功、失败与恢复；状态/权限/数据/接口缺口先回到设计。
- [拆分与停止](splitting-guide.md)：模块按职责、数据、契约与验证边界划分；文件按职责与可理解性划分，不用固定数量拆分。
- [架构决策](universal-quality.md#架构决策)：以真实驱动比较合理候选，记录理由、代价、负面后果、验证与重评条件，不编造规模或SLO。

## 事实归属

- [递归模块](recursive-modules.md)：每个受管模块一份架构，可任意有限深度包含子模块，各层都可拥有源码与测试。
- 根保留全局目标、约束、共同契约与导航；模块保留局部功能、行为、状态、契约、源码与测试责任。上层引用，不逐层抄录全文。
- 包含关系与依赖关系分开；模块目录由路由派生，依赖按真实声明与消费者核对，不从父子关系猜调用。
- [14项模块语义](../../skills/architecture-json/SCHEMA.md#模块详情底线)保留职责/非职责、功能归属、上下游、内部结构、状态、数据、错误、配置、安全、日志审计、性能与测试；无相关责任可简短说明不适用。
- [契约与细节](schemas.md)：公共接口的签名、错误和消费者在权威契约维护；计划、实现和测试记录引用它。真实代码标识符/路径保留原样，规范主键与说明使用中文。
- [旧集中布局](json-sharding.md)按登记入口继续工作，不为形式迁移源码。

## 影响、协作与专业方法

- [影响分析](association-and-priority.md)：从当前变更出发，按行为、契约、状态、副作用与消费者扩展；签名未变也检查实际影响，只改已确认范围。
- [动态姿势语境](task-posture.md)：阶段、风险、作用域、触发与退出条件校准当前工作；已有语境复用，轻量工具不代替工程判断。
- [模块智能体](module-agent-protocol.md)：临时责任边界可覆盖已授权的多个模块；未裁决提案先记录，已确认变更按明确分工继续，共同文件避免并发覆盖。
- [专业能力](capability-index.md)：按已确认任务与真实可用性选最小必要方法，已有合适来源优先；无能力时记录限制，不默认载入全部参考或上游。
- [UI质量](capability-index.md#ui-质量门禁)：视觉方向、设计系统、图标语义、适用交互状态和真实渲染验收各有责任，不把图标库数量当质量。

## 验证与接力

- [批次校验](../../skills/xl-ai-language/LAYER.md#工具与完成契约)：同一相关批次校验一次，只推进真实完成的阶段；设计进行中不要求最终门禁先过。
- [21项与门禁](validation-checklist.md)：按适用性检查，结构通过不等于所有语义已检查；完整交付运行 `gate_check --quality-required`。
- [真实质量证据](universal-quality.md)：声明/推断、模型review、实际execution和未知分开；0/1/2分别表示选定检查通过、失败、无法判定。
- [执行记录](execution-templates.md)：对外报告实际变化、结果与证据路径，未变化字段不反复写“无”。
- [恢复点](context-recovery.md)：保存最小续跑事实、用户约束、下一步和权威证据引用；模块交接信息由根引用，不复制失败全文与全部历史。
- [完成首行](../../skills/xl-ai-language/LAYER.md#工具与完成契约)：完整交付使用 `【任务完成】` 或 `【未通过验证】`，局部运行只报告本次结果。
