# 执行记录

任务范围、启动回执、状态读取和完成首行以 [LAYER](../../skills/task-architecture/LAYER.md) 为准。本文件给出可按本次变化选取的记录示例，不要求每轮复述完整模板。

## 任务前置输出

首次说明任务类型、主要影响范围、执行档位和下一步。内部核对用户要做/不要做的细节、验收信号、实际架构入口、所需信息层与最低交付条件；已有明确需求和授权可直接推进。范围未变不重复输出；未裁决且会影响实施的关键边界才澄清。

页面、按钮、字段、接口、文案、状态和异常等明确要求都应可追踪，不能用“优化 UI”“修 Bug”抹去具体要求。架构从实际入口解析，按拥有本次事实的模块或既有切片落位。

## 注意力预算

按顺序聚焦用户需求与约束、相关架构/代码、实际依赖和消费者、必要验证与恢复位置。资料按关联节点分批读取；功能全景、相关异常和验证责任仍需充分展开。全局治理、迁移与更远扩展仅在本次需要时进入，不以流程性汇报替代结果。

## 架构修改前后对比

每个相关变更批次给出实际变化与证据位置，例如：

```text
架构变化：新增/修改/废弃的实际节点及原因
影响：相关模块、契约、源码与测试，仍待确认的影响
验证：实际结果及权威证据位置
继续位置：未完成事项与下一步（存在时）
```

只列发生变化或影响交付的项，未变化字段无需写“无”。已有工具预览或变更记录可作为详细对比，主会话概括结果并给路径。下游影响依据行为、契约、状态和消费者判断，见 [影响范围](association-and-priority.md)。

## 变更类型与落位

下表列出需核对的事实，不要求在全部区域重复同一内容。只更新实际变化的权威事实；其他节点引用其编号、文件/Pointer或证据路径。递归布局按 [模块归属](recursive-modules.md)；既有集中布局按 [切片协议](json-sharding.md)。

| 变化 | 核对并更新实际受影响事实 | 验证重点 |
|---|---|---|
| 页面、组件、UI设计 | 功能验收、入口/页面归属、状态与反馈、资源和实现责任 | 重要状态、响应式/输入方式、图标语义、真实渲染与交互 |
| API/RPC/消息/SDK | 公共接口契约、消费者、入口、实现与兼容约束 | 正常/异常/边界、调用点和兼容路径 |
| CLI、后台任务、系统入口 | 参数或触发、生命周期、状态/副作用、模块与文件归属 | 退出/失败/恢复、适用的幂等、重试与权限 |
| 数据结构或表 | 数据归属、字段约束、相关契约与迁移/恢复方案 | 读写、迁移、失败恢复和回归 |
| 交付物或系统集成 | 运行形态、产物/配置/资源、外部契约及负责模块 | 构建、启动、适用的安装/卸载/更新/回滚与真实环境边界 |
| Bug修复 | 根因涉及的行为/错误边界、回归责任和实际变更 | 复现、修复前后对照、受影响消费者或同类路径 |
| 性能优化 | 真实性能目标、约束与实现变化 | 同口径测量、输入与环境、未验证边界 |
| 模块重构或依赖变化 | 职责/归属、包含与依赖、契约及文件清单 | 依赖规则、调用行为、真实回归 |

已有设计覆盖的实现修复，不为留痕重写功能树或契约。补本次变更、测试与影响依据；设计确有缺口时先补相应事实再编码。每批次变更记录保留时间、原因、影响、验证结论及证据引用；按 [字段归属](recursive-modules.md#根级字段与模块局部记录) 写根级记录或模块局部记录。

## 完成定义

依据 [校验清单](validation-checklist.md) 复核本次范围：明确要求均有结果或未完成理由；适用架构事实与实现一致；实际验证与未知项可追查；未完成事项有可继续的位置。完整实现交付按 [通用质量](universal-quality.md) 运行统一门禁，不用单一结构退出码代替全部21项语义与真实行为验证。

只维护一份验证详情。根级 `验证证据` 保存命令/操作、结果与实际产物位置；根级 `上下文恢复点` 保存对继续执行有用的状态、下一步及证据引用；根级 `变更记录` 保存全局变化及结论。模块自己的变化与证据索引按上述字段归属写局部记录，不把这些保留键写入子文件顶层。相同失败、浏览器边界或未验证说明不在三处全文复制。需要定位的引用应包含实际文件及必要的节点/JSON Pointer。

## 失败恢复

测试失败、实现卡住、依赖缺失或即将中断时，按 [上下文恢复](context-recovery.md) 更新当前失败位置、已确认事实、不要重复的操作、未完成事项与下一步。错误全文和命令输出留在证据产物；恢复点引用它们，并保留执行所需的关键事实。

恢复点在根当前事实或明确登记的任务记录中维护一份；模块保留自己的交接信息，根引用模块编号与继续路径。既有集中布局使用登记任务切片，不另建未登记的索引副本。最终说明实际失败、下一步及未验证边界，状态改变前不重复贴相同失败模板。
